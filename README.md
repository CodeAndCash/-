# C&C Family — один бот и одно приложение

Главный бот (@CodeAndCash_bot) только открывает мини-приложение. Всё остальное внутри:

- **Главная** — видео-заставка, в карусели «Навигация» и курс, лента: первым постом навигация, дальше уроки и подборки с сайтами.
- **Навигация** — страница для новичков: 8 ступенек от первого урока до первого клиента, где что лежит, поддержка.
- **Категории** — курс (5 модулей, 19 уроков), парсер, оценка работ, марафон, скиллы (88), плагины (33), промпты (67), материалы (10), ресурсы, AI-офис, чат резидентов.
- **Скиллы и плагины** — как у SGX: памятка «Как выбирать», фильтры, разделы, «Главное для сайтов» (UI и UX), авторские C&C для резидентов, у каждого команда установки и источник. Бесплатно: 10 скиллов и 6 плагинов.
- **Промпты** — 67 штук в 7 разделах, 10 бесплатных.
- **Чат резидентов** — описание закрытого чата. Гость видит «Подать заявку» под замком, резидент жмёт и попадает в чат — бот одобряет заявку сам.
- **Парсер** — прежний бот, теперь внутри приложения. Во вкладке «Скрипты» — скрипты по нишам и библиотека «Мои скрипты» со всеми сохранёнными по всем нишам.
- **Оценка работ** — человек прикрепляет скриншоты и видео прямо в приложении, заявка уходит команде, ответ приходит в чат.
- **Профиль** — доступ, тёмная тема, уведомления, «Проверить доступ», поддержка, админка.
- **Тарифы** — «Резидент» (материалы и инструменты) и «С наставником» (под замком, «скоро откроется»).
- **Админка** — статистика, люди и доступ, оплаты, тарифы и цены, материалы, рассылка, тексты бота.

Что происходит само:

- Оплатил картой (Tribute) или криптой (CryptoBot) → открывается всё, бот одобряет заявку в закрытую группу или присылает личную ссылку.
- Гость подал заявку в группу → бот пишет ему про тарифы; после оплаты одобряет заявку сам.
- Открыл оплату и не оплатил → через 3 минуты сообщение «Видим, что ты открывал оплату…» с кнопками «Открыть C&C» и «Написать лично».
- За 3 дня до конца доступа — напоминание. Закончился → бот убирает из группы и закрывает парсер.
- Число участников берётся из закрытой группы и обновляется само.
- Новый день марафона открывается на следующий день, бот напоминает.
- Любое сообщение боту → «Бот только открывает приложение…» с кнопками «Открыть C&C» и «Поддержка».
- В меню команд только /start. Слева от поля ввода — кнопка «C&C».

## Запуск на Railway

Нужен один сервис вместо трёх старых.

1. Загрузи папку проекта: `railway init` → `railway up --detach` (или через GitHub).
2. **Volume**: Railway → сервис → Settings → Volumes → Add, путь `/data`.
3. **Домен**: Settings → Networking → Generate Domain. Скопируй адрес.
4. **Variables** — минимум:
   ```
   BOT_TOKEN=токен @CodeAndCash_bot
   ADMIN_IDS=8793693829, @fuckprincov, @SUN9ISE
   PUBLIC_URL=https://адрес-из-шага-3
   DATA_DIR=/data
   SUPPORT_USERNAME=SUN9ISE
   ```
   Остальное — в `.env.example`. Ключи нейросети и источников парсера переносятся из старых сервисов как есть.
5. Проверка: открой `адрес/healthz` — должно быть `{"status":"ok"}`. Напиши боту /start.

Старые сервисы парсера, скриптов и оценки нужно **остановить**: один токен не может работать в двух местах.

### Перенести данные старых ботов

Пользователи, лиды, ключи и заявки сохранятся, если положить старые базы в `/data` нового сервиса под именами:
`parser.db`, `script.db`, `evaluation.db`. Сделать это можно через `railway ssh` или временно подключив старый volume.
Если не переносить — всё начнётся с чистого листа, курс и материалы загрузятся сами.

## Настройка в @BotFather

1. **Кнопка «Открыть приложение» в описании бота**: Bot Settings → Configure Mini App → Enable Mini App → вставь `PUBLIC_URL`.
2. **Аватарка**: Edit Bot → Edit Botpic → `cc/assets/avatar.jpg`.
3. **Картинка в «Что умеет этот бот?»**: Edit Bot → Edit Description Picture → `cc/assets/welcome.jpg`.
   Текст описания бот ставит сам при запуске.
4. **Анимация в описании** (по желанию, вместо картинки): Edit Description Picture → `cc/assets/description.mp4` (640×360).

## Оплата картой через Tribute

1. В Tribute создай цифровой товар «C&C Family — доступ на месяц» (или подписку) с ценой тарифа.
2. Creator Dashboard → Settings → API Keys: создай ключ → `TRIBUTE_API_KEY`. Там же вебхук: `PUBLIC_URL/api/pay/tribute`.
3. В приложении: Админка → Тарифы → у «Резидента» впиши ссылку на товар и его ID.

Человек жмёт «Оплатить картой» → открывается Tribute → после оплаты Tribute сообщает боту, и доступ открывается сам.
Если в Tribute подписка, доступ действует до даты, которую прислал Tribute, и продлевается с каждым списанием.

## Оплата криптой

@CryptoBot → Crypto Pay → Create App → токен в `CRYPTO_PAY_TOKEN`.
Чтобы оплата засчитывалась мгновенно: там же Webhooks → адрес `PUBLIC_URL/api/pay/crypto`.
Без вебхука бот всё равно проверяет счета каждые 20 секунд.

## Закрытая группа

1. Добавь бота в группу C&C Family и сделай админом с правами «Пригласительные ссылки», «Блокировка участников» и «Принимать заявки».
2. Бот сам пришлёт админам ID группы — впиши его в `GROUP_ID`. Ссылку с заявками впиши в `GROUP_LINK`.
3. Заявки резидентов бот одобряет сам, гостям пишет про тарифы.

Кто уже в группе, получает доступ кнопкой «Проверить доступ». Кому ты выдал доступ вручную в группе — его бот не трогает, пока он там.

## Чат резидентов

Ссылка уже вписана: `https://t.me/+wvw9cMktwFphYjgx` (поменять — переменная `CHAT_LINK`).

1. Добавь бота в чат и сделай админом с правами «Пригласительные ссылки», «Блокировка участников» и «Принимать заявки».
2. Бот пришлёт админам ID чата — впиши его в `CHAT_ID`.
3. Резидент жмёт «Подать заявку» в приложении — бот одобряет сразу. Гостю бот пишет про тарифы и одобрит заявку сам после оплаты. Закончился доступ — бот убирает из чата.
